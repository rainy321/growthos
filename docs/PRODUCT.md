# Growth OS 产品说明

## 一句话定位

面向经常制定长期目标、但计划会被现实打断的学习者与知识工作者，Growth OS 用“导航—偏航—重规划”的方式把每天的真实行为变成更适合个人的下一版计划。

## 核心用户任务

用户打开产品时，不应先看到复杂数据，而应迅速回答三个问题：

1. 我长期要去哪里？
2. 今天只需要完成哪个航点？
3. 最近的偏航告诉我应该怎样调整？

## 与 Todo / 打卡产品的区别

- Todo 管理任务库存；Growth OS 管理目标与现实之间的反馈回路。
- 打卡产品强调连续数字；Growth OS 允许如实记录失败，并把失败原因当成导航信号。
- 普通 AI 规划生成一次方案；Growth OS 让方案随行为数据持续变化。

## 设计系统

- **隐喻**：路线图、航点、偏航与重新导航。
- **主色**：深水墨 `#17343A`、导航青 `#2F7D78`、信号珊瑚 `#EF6A5B`、雾面底色 `#EDF4F3`。
- **字体角色**：宋体系标题表达长期方向；无衬线正文保证操作清晰；等宽数字用于日期和指标。
- **标志性元素**：贯穿产品的“成长航线”，当前航点用珊瑚色标记，偏航不被画成失败状态。

这一方向替换了早期常见的暖米色植物卡片模板，使视觉语言直接承载产品机制。
